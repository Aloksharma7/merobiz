# MeroBiz access & immediate-sales update — 2 September 2026

This update keeps the simplified three-role model and removes the employee-sale approval workflow.

## Roles

- **Owner** — portfolio-wide access, business financials, ownership, reports, team and settings.
- **Admin** — assigned-business operations, financials, employees, expenses and all sales.
- **Employee** — assigned business only; personal sales workflow, customers, catalogue and payments permitted by the role.

An employee assigned only to TechChamp Software cannot see another MeroBiz business, portfolio financials, ownership, reports, expenses, team administration or internal costs. Laravel enforces this scope server-side.

## Sales behavior

Employee sales no longer require approval. When an employee creates an issued invoice, it is immediately part of:

- business sales;
- staff sales performance;
- commission calculations;
- receivables;
- business profit calculations.

Owners and admins can view employee sales, but there are no Verify/Reject buttons or approval endpoints. Invalid unpaid entries use the normal cancellation flow.

Legacy verification columns remain internally for safe upgrades from the previous build. The new migration automatically converts any old pending sale to accepted so an existing database does not get stuck. The UI/API do not expose an approval workflow.

## Upgrade an existing Laragon installation

After replacing the update files, run:

```powershell
cd D:\merobiz-os\merobiz-os\api
php artisan optimize:clear
php artisan migrate
php artisan serve
```

Then restart the frontend:

```powershell
cd D:\merobiz-os\merobiz-os\web
npm install
npm run dev
```

Do **not** use `migrate:fresh` if you want to preserve your existing records.
